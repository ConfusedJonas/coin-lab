## Repository lore
I saw a probability puzzle on Reddit but didn't trust the answers I saw, so i vibecoded this webstie to visualize the results (I proved myself wrong).

### The puzzle
I flip a penny and a dime and hide the results from you. "At least one of the coins came up heads," I announce. What is the chance that both coins came up heads?
